# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2026-08-08

### Added

- Native desktop-style Tkinter interface packaged as a Windows executable
- Deterministic manual Chrome launch workflow
- 5-second baseline before launch
- 250 ms performance sampling
- 60-second startup capture
- Chrome CPU, system CPU, Chrome RAM, process-count and disk-throughput timeline
- Top-process capture
- Privacy-reduced Chrome process snapshot
- Extension inventory
- Defender status
- WHEA Event ID 17 collection
- PCIe device/driver inventory
- Local CSV, JSON, text and ZIP reports
- Inno Setup installer/uninstaller
- GitHub Actions CI and release build pipeline
